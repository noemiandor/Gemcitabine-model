# Adopted Figure 7 layout

- Target: 7.1 x 10.645 inches (two-column/full-page journal figure).
- Reading order: A--L, row major, using the enforced manuscript identity map.
- Rows: A/B; C/D/E; F/G; H; I/J; K/L.
- The 6.9225-inch usable width is allocated by row as 18:10, 9:10:9,
  10:18, full width, 11:17, and 14:14.
- C--E each receive 1.35 inches of height so the three joint UMAP views remain
  distinguishable at print size.
- H receives the full width and 1.45 inches of height for the three ECDF
  comparisons. The detailed density-localization analysis is displayed as
  Supplementary Figure 4I rather than compressed beneath H.
- I and J share a 2.745-inch penultimate row. Display-only abbreviations retain
  I's pathway identities in 11/28 of the usable width, while J receives 17/28
  for the three annotation bars, their complete compact key, all 22 chromosome
  columns, a sparse chromosome-label sequence, and its color scale.
- The bundled optimizer was run on the six scientifically constrained row
  groups. Its independent candidate and report are retained beside this plan;
  `layout_plan.csv` records the adopted row-major geometry.
- Coordinates use lower-left origins; `y_npc` is not inverted.
